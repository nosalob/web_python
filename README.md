# Guestbook Skeleton

Bộ khung dự án Guestbook gồm hai hướng triển khai:

- `1_vibe_code/`: cấu trúc Flask đơn giản để phát triển nhanh.
- `2_manual_code/`: cấu trúc tách controller, service và repository.

## Bắt đầu

1. Giải nén bộ khung.
2. Mở terminal tại thư mục `guestbook-skeleton`.
3. Chạy `push_skeleton_to_github.bat` trên Windows để khởi tạo Git và push lên GitHub.

Yêu cầu: đã cài Git và đã tạo một repository trống trên GitHub.

Các file có ghi `TODO` là vị trí để bổ sung code sau.
